# Bot findings — YYYY-MM-DD

> Save one file per day as `shared/bot-findings/YYYY-MM-DD.md`.
> **Append only.** Never edit or delete another bot's entry. Every bot reads today's file before posting so nothing gets reported twice.
> Clipboard Chloe rolls this file up into the owner's check-ins.

## Heading format (required: the roll-ups and the pixel office parse it)

    ## <Bot Name> - <h:mm AM/PM your local time>

## Entry format

    ## Pipeline Paris - 9:05 AM
    1. <Account> (new logo | expansion | retention) — <what happened>
       Why now: <one line>
       Next step: <who> does <what> by <when>
       Source: <record / message / meeting + time>
       Draft (optional): <plain text, ready to paste>

    ## Signal Sienna - 10:02 AM
    Nothing new since 9:02 AM.

## Rules for entries
- Cite a source for every item. Quotes are labeled verified / unverified / paraphrase.
- Numbers come from a named report or record. Otherwise write `[GAP: why]`.
- If another bot already covered it today, skip it or add only the new fact ("adds to Paris 9:05 AM: …").
- No secrets, passwords or tokens. Keep personal details to what's needed.
